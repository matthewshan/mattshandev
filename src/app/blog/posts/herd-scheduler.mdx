Pick a few candidate days, set a time range, optionally make responses
anonymous, and you get a shareable link.

## Tech stack

The whole thing is built to be **portable** — one container image, any Postgres
via a single `DATABASE_URL`, no host-specific services.

- **Next.js (App Router, TypeScript)** — `output: 'standalone'` for a small,
  self-contained production image. Server components + server actions, no
  separate API layer.
- **PostgreSQL via Prisma** — single `DATABASE_URL`, no provider-specific
  features. Times stored in UTC, displayed in the poll's timezone.
- **Auth.js v5 + Google OIDC** — Prisma adapter with database sessions.
  Voting needs no account; creating polls is access-gated.
- **Tailwind CSS** — design tokens from a Claude Design handoff, with a
  `data-theme` light/dark toggle.
- **Self-hosted fonts** (`next/font`: Space Grotesk + Inter) and **lucide-react**
  icons — bundled into the image, no runtime CDN.
